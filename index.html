Here you'll find material about Control Systems II, Control Systems I, Informatik II and other additional resources for the bachelor in mechanical engineering at ETHZ.

Control Systems II

Discrete Time Systems, Diagonalization, State Feedback, State Estimation, Seperation Principle, LQG, Lyapunov, Nonlinear Control, MPC, Optimization.

Control Systems I

Modelling, System Classification, Time Response, Stability, Transfer Functions, Poles and Zeros, Root Locus, Time Specifications, PID, Frequency Response, Nyquist, Frequency Specifications, Time Delay, Describing Functions, Uncertainty.

Informatik II

Python Libraries, Classes, Programming Concepts, Algorithm Design, Searching and Sorting, Trees, Dynamic Programming, Decision Trees, Linear Regression, Cross-Validation, Neural Networks, Deep Learning, Supervised/Unsupervised Learning, Dimensionality Reduction.
